# LLM Prompt Benchmark

A benchmarking tool for evaluating LLM prompting techniques on the IMDb
sentiment analysis dataset.

## Features

- Zero-shot prompting
- Few-shot prompting
- Instruction-based prompting
- IMDb dataset support
- Accuracy, Precision, Recall, F1
- Latency and token usage benchmarking

## Tech Stack

- Python
- LiteLLM
- Hugging Face Datasets
- Pandas
- scikit-learn
